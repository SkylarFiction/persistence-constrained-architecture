Classify whether a user message proposes Lucien growth.

Growth types:
- memory: recallable fact or context
- skill: reusable procedure or capability
- preference: stable interaction tendency
- commitment: standing promise or obligation
- policy: operating rule
- identity: self-definition or continuity-boundary change

Do not treat every message as growth. Identity, policy, and commitment changes
require review. Raw user text should not be stored as identity memory.
