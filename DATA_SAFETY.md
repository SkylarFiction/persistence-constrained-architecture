# Data Safety and Research Storage

Lucien/PCA treats `/Users/nickwhitehead/Desktop/Master files /` as a knowledge hub.

## Read-Only Source Rule

Existing files in Master Files are source material. Lucien may catalog, hash, read, summarize, and cite them through governed evidence workflows, but it must not delete, move, rename, rewrite, normalize, or overwrite those source files.

## Generated Research Rule

New research outputs must be written separately under:

```text
/Users/nickwhitehead/Desktop/Master files /knowledge_hub/generated/research_papers/
```

Reader-facing papers and audit bundles should be timestamped when generated from the live app so each run creates a history instead of overwriting prior work.

## Reuse Rule

Generated papers may become future source material, but they must remain marked as generated Lucien/PCA outputs. They should not be counted as independent external corroboration of the original source archive.

## Internet Research Rule

Future internet research should import metadata, abstracts, citations, and permitted full text only from legitimate sources. External papers must be tagged as external literature and kept separate from Skylar's own Coherence Physics archive until reviewed.

## Prohibited Actions

Lucien/PCA should not:

- delete existing Master Files documents
- rewrite source PDFs or books in place
- treat generated drafts as peer-reviewed sources
- auto-publish papers
- download copyrighted full-text papers unless access is legitimate
- count duplicate local copies as independent support
